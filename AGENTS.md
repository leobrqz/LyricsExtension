# Repository guidance

Before preparing, publishing, or editing a GitHub release, read `.codex/skill/GH-RELEASE/SKILL.md` when it exists. It contains the local release workflow and release-note style.

Keep maintainer publishing instructions in the ignored `.codex/` directory. The README covers the product, downloads, installation, and development. Never force-add `.codex/` or `docs/` to Git.

Speak Portuguese with the user. Write repository documentation, commit messages, and release notes in English.
